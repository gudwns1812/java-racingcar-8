# java-racingcar-precourse
# 기능 요구사항

- [x]  자동차 생성
    - [x]  사용자에게 이름을 받기
    - [x]  이름의 크기 제한 검증
- [ ]  자동차 이동
    - [ ]  사용자에게 이동할 횟수 입력 받기
    - [ ]  입력값이 0보다 큰 수 인지 검증
    - [ ]  무작위 값을 이용하여 4이상 조건 체크
    - [ ]  조건을 만족하는 자동차만 이동
- [ ]  자동차 이동 결과 비교
    - [ ]  이동이 모두 끝난 후 자동차들의 결과 비교
    - [ ]  우승 자동차 이름을 사용자에게 출력
